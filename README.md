# RPG Character Manager

My first C++ console RPG project built while learning software development and C++ fundamentals.

This project is part of my learning journey and is developed with AI assisted guidance. Every feature is implemented step by step with the goal of understanding the underlying C++ concepts rather than simply copying code.

## Features

- Create a custom RPG character.
- Fight random monsters.
- Heal your character.
- Earn gold from battles.
- Gain experience (XP).
- Level up your character.
- View character statistics.
